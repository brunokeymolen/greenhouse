DIN Rail mount for ESP 01S incl. Relay module by NobodysNightmare on Thingiverse: https://www.thingiverse.com/thing:4821541

Summary:
This is a DIN Rail mount for an ESP 01(S) including the standard relay module for it.Depending on how the print comes out, this will either tightly fit or the module can slide out itself. However, you will always be able to align it on the right side, so once mounted even a loose fit should not be a problem.Supports from the print bed are required.
